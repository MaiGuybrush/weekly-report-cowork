# 以單一工作編號綁定週報項目並自動同步進度

課長要把工程師工作挑進週報，並在往後每週看到進度變動。每個週報項目綁定一個工程師工作編號，一個工作編號全站只能綁一個項目；重傳彙整時依編號比對，自動更新進度（關鍵任務另對應狀態），並以徽章呈現原值供課長確認。課長手動覆寫進度後，自動同步暫停。

這取代原本「關鍵任務可掛多筆佐證、摘要必填」的來源連結。多筆佐證較有彈性，但進度變動就沒有單一來源可比較；單一綁定讓「+xx%」有明確基準（上週最後正式版），也讓更新判斷只看工作編號。代價是一個任務若對應多個工作，必須由課長挑其中一個代表，或拆成多個任務。
