# 決定非專案章節的入選與管理規則

## Question

重要新增需求、重大系統異常、人事異動及新技術評估，各自何時進入處會週報、由誰維護與何時結案？哪些內容需要特別限制可見範圍？

## Comments

- 2026-09-26 Resolution: 重要新增需求由課級主管自行決定是否納入正文。目前可從既有工程師 eCIM 工作匯入候選項目；未來可串接尚未提供的需求單 MCP，取得本週新增需求供課級主管挑選。
- 2026-09-26 Resolution: 系統可從 eCIM 工作提示疑似異常候選；是否屬重大系統異常並納入週報由該課課長決定。納入後記錄影響範圍、處置、恢復狀態及後續改善。
- 2026-09-26 Resolution: 人事異動草稿僅 Guy 與相關課長可查看及編輯；其他課長不可見。正式發布後僅有處會報告讀取權限者可見。內容限生效日期、職責交接與對工作的影響。
- 2026-09-26 Resolution: 新技術評估自評估中即可納入，逐週記錄問題、評估標準、證據與下一步；以採用、續試或停止記錄結論。
- 2026-09-26 Resolution: 由負責課長確認結案，本週保留一次結案摘要，下週退出正文並保留歷史。異常復原後若永久改善仍未完成，改善項目繼續追蹤。
