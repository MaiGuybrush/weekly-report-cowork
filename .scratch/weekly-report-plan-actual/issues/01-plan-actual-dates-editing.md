# 01 — 課長以計畫／實際兩組日期維護時程

**What to build:** 課長編輯階段、關鍵任務、重要里程碑時，日期欄位只有「計畫」與「實際」兩組；改期直接覆寫計畫，不再區分「更正原始計畫」與「一般改期」。日期優先序為「實際否則計畫」（相依檢查與警示行為不變）。偏差天數為實際相對於計畫，未完成或未達成顯示「—」。儲存的 JSON 只含新欄位，舊的原始與預測欄位直接忽略、不遷移。甘特圖暫時只畫計畫條，維持可用不退步（完整的計畫條加實際條由票 02 處理）。

依據：[計畫／實際兩組日期規格](../../../docs/plan-actual-dates-spec.md)；[計畫／實際兩組日期](../../weekly-report-simplified/issues/08-plan-actual-two-dates.md)。

**Blocked by:** None — can start immediately.
