# 11: 候選決策與人工覆寫保護

**What to build:** 課長能比較 eCIM 最新值與週報內容，逐項接受、合併、暫緩或忽略候選；手工修改過的欄位在重匯時保留報告值，由課長決定維持人工版或套用來源。

**Blocked by:** 10 — eCIM 課別同步與來源狀態。

**Status:** ready-for-agent

- [ ] 候選池區分新增來源、進度或狀態變更、疑似完成及異常提示；是否屬重要需求或重大異常仍由課長決定。
- [ ] 同步欄位保存上次來源值、最新來源值、目前報告值與人工覆寫狀態；重匯不直接改寫人工值。
- [ ] 課長選擇建立、合併、暫緩、忽略、維持人工或套用來源後，畫面與共用項目顯示正確結果並留下紀錄。
- [ ] 重匯、來源失敗及欄位衝突情境通過 HTTP 行為測試；已發布版始終不變。
