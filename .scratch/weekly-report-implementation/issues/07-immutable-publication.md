# 07: 發布快照與固定版號連結

**What to build:** Guy 能從目前工作草稿發布一致的正式週報，取得固定版號與連結。正式頁按六段章節呈現，讀者只看得到有權查閱的發布內容；Guy 後續可編輯並重新發布，舊版保持原狀。

**Blocked by:** 04 — 管理摘要與非專案章節；05 — 結構化專案時程；06 — 人事內容與正式版讀者權限。

**Status:** ready-for-agent

- [ ] 只有 Guy 能發布；發布結果含版號、時間、發布者與固定 URL，重試同一請求不意外新增版本。
- [ ] 正式頁從不可變快照讀取；發布後修改工作草稿不改變舊版，重新發布產生新版與新 URL。
- [ ] 授權讀者可讀指定發布版，名單外與未登入者不能取得內容；人事內容由後端按讀者權限提供。
- [ ] 同時有人提交其他項目時，發布版仍是一份一致的工作版快照；以 HTTP 與暫存 SQLite 驗證。
