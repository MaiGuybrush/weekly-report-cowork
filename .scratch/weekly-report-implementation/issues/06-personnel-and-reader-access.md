# 06: 人事內容與正式版讀者權限

**What to build:** Guy 與相關課長可維護人力與組織異動項目；無關課長看不到該草稿。列入 SQLite 讀者名單的人可登入唯讀入口，在尚無發布版時看到明確提示；名單外的人不能藉連結取得內容。

**Blocked by:** 02 — 項目編輯、租約與私有草稿。

**Status:** done

- [x] 人事項目只包含生效日期、職責或系統交接、影響與下一步；Guy 和相關課長可讀寫，其他課長從清單與直接 API 存取都無法取得。
- [x] 讀者名單可由部署設定初始匯入，後續透過受控管理操作調整並留下稽核紀錄。
- [x] 列名讀者登入後只見唯讀入口，不可讀工作草稿或呼叫編輯 API；無發布版時顯示「尚無正式發布版」。
- [x] 未列名且無編輯角色的人即使取得週報 URL，也收到明確的無權限結果。
