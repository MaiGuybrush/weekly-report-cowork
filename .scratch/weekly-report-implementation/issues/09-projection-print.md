# 09: 投影與瀏覽器列印版式

**What to build:** 處會讀者能在螢幕與投影設備快速閱讀已發布版，並以瀏覽器列印或輸出 PDF。正式頁保留版號、時間、章節、來源狀態與專案摘要。

**Blocked by:** 07 — 發布快照與固定版號連結。

**Status:** ready-for-agent

- [ ] 已發布版有清楚的投影與列印布局，顯示版號、發布時間、管理摘要、專案、維運、人事、技術評估與來源附錄。
- [ ] 長文字、專案清單及人事內容在常見瀏覽器列印預覽中不被側欄或操作按鈕遮擋；固定連結列印仍指向同版。
- [ ] 尚未接入或同步失敗的來源狀態如實顯示，不呈現為零工作。
- [ ] 用具真實長度的代表性資料檢查投影與列印結果，並保留可重複的瀏覽器驗收流程。
