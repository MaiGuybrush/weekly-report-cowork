# 04: 管理摘要與非專案章節

**What to build:** Guy 與課長能以章節導覽和可收合側欄維護本週管理摘要、重要新增需求、重大系統異常及新技術評估。每件事有一張主項目卡；摘要引用主卡，課長自行決定哪些需求或異常進入正文。

**Blocked by:** 02 — 項目編輯、租約與私有草稿。

**Status:** ready-for-agent

- [ ] 課長能在所屬課別建立、修改、結案需求、異常與技術評估項目，並輸入規格所需的本週變化、負責人及下一步。
- [ ] Guy 可整理本週管理摘要、優先順序及跨課項目；摘要指向主卡，不產生第二份可獨立編輯的同一事實。
- [ ] 編輯器可收合章節導覽、來源對照及預覽，保留足夠的主要編輯寬度。
- [ ] 尚未接入 eCIM 的來源區標示為未連接；沒有候選時也不宣稱本週沒有工作或重大異常。
