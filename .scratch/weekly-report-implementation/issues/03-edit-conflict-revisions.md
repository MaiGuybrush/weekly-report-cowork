# 03: 同項目衝突與修訂紀錄

**What to build:** 兩位編輯者同時處理同一項目時，後進者能讀取已提交版本及持有人資訊，租約到期或版本變動時可比較自己的私有草稿與最新版本。Guy 可在必要時附理由接管租約；所有提交與接管可追溯。

**Blocked by:** 02 — 項目編輯、租約與私有草稿。

**Status:** done

- [x] 同一項目只有一個有效租約；其他編輯者不能提交，並看到持有人及到期時間。
- [x] 租約逾時、失效 token 或舊 `baseVersion` 提交時回應衝突，保留私有草稿及可比較的最新內容，沒有靜默覆寫。
- [x] Guy 接管需填原因；接管與每次成功提交均可查操作者、時間、前後版本。
- [x] 四人編輯不同項目可同時成功；兩人競爭同一項目及到期恢復情境通過 HTTP 併發驗證。
