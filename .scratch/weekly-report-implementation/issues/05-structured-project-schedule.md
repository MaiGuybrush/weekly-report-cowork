# 05: 結構化專案時程

**What to build:** 週報維護人能在專案卡與表單中記錄健康度、階段、重要里程碑、計畫基準、目前預估、實際日期，以及風險、問題、相依與待決策事項。第一階段以清單和日期表單呈現。

**Blocked by:** 02 — 項目編輯、租約與私有草稿。

**Status:** ready-for-agent

- [ ] Guy 可指定四位共同編輯者之一為週報維護人；維護人可更新專案整體資訊，實際專案負責人另行記錄。
- [ ] 階段與里程碑可分別保存基準、預估與實際日期；專案頁清楚顯示差距，不依工程師工時推算完成率。
- [ ] 變更計畫基準必須填原因，且可檢視變更前後日期、操作者與時間；其他日期更動不刪除歷史。
- [ ] 課長只能更新所承擔工作並提出時程調整；越權修改專案整體資料時後端拒絕。
