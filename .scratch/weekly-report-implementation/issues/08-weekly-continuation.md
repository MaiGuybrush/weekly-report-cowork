# 08: 建立下週草稿與事項延續

**What to build:** Guy 可依前週最新已發布版建立下週草稿，延續未結案項目、來源連結及待決策事項；完成項目在結案當週留一次摘要，下週退出正文，歷史仍可查。

**Blocked by:** 07 — 發布快照與固定版號連結。

**Status:** ready-for-agent

- [ ] Guy 指定處會日期建立下週唯一草稿，內容取自前週最新發布版，不取未發布修改或較舊發布版。
- [ ] 未結案項目保留穩定跨週識別、負責人及上週承諾；待決事項在新週需填結果或新期限，不能無聲消失。
- [ ] 本週結案項目在本週保留一次摘要，建立下週草稿時不再進正文；舊版及歷史仍可查。
- [ ] 相同日期重試建立不產生重複草稿；課長或讀者不能建立。
