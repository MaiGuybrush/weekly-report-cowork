# 12: 專案甘特圖

**What to build:** 週報維護人與處會讀者可用甘特圖檢視專案階段、重要里程碑、計畫基準、目前預估與實際日期。維護人點選圖上項目後仍以表單修改日期及原因。

**Blocked by:** 05 — 結構化專案時程。

**Status:** ready-for-agent

- [ ] 甘特圖以既有結構化階段與里程碑為資料來源，顯示報告日、基準、預估、實際與偏差，不逐筆繪製工程師工作。
- [ ] 已完成階段可折疊；專案摘要先突出接下來的重要階段與里程碑。
- [ ] 維護人可由圖進入日期表單，變更基準須填原因，並能檢視歷史基準；拖曳圖形不直接修改日期。
- [ ] 編輯預覽、正式頁及瀏覽器列印能讀懂時程偏差，且日期與專案表單一致。
