# 02: 項目編輯、租約與私有草稿

**What to build:** 課長能在所屬課別新增項目，取得 30 分鐘排他租約，編寫時自動保存只供自己查看的草稿，按「儲存完成」後才更新共同週報。Guy 可編輯授權範圍內的項目。

**Blocked by:** 01 — UAC 登入與建立首份週報。

**Status:** done

- [x] 課長可新增及編輯所屬項目；編輯時顯示租約持有人與到期時間，持續操作可續期。
- [x] 自動暫存只讓該編輯者讀取；另一位編輯者仍看到最後已提交內容，不看到私有草稿。
- [x] 提交時同時檢查權限、租約 token、項目版本與欄位有效性，成功後共用版本遞增並釋放租約。
- [x] 未持有有效租約、越權或提交無效內容不能改動共用項目；以 HTTP 與暫存 SQLite 測試可觀察結果。
