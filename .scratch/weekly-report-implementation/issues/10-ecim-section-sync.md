# 10: eCIM 課別同步與來源狀態

**What to build:** 課長可手動同步所屬課別工程師的本週 eCIM 工作，看到每位成員的成功或失敗、資料期間與上次成功時間，並檢視新來源候選。此為第二階段的第一條可展示整合流程。

**Blocked by:** 04 — 管理摘要與非專案章節。

**Status:** ready-for-agent

- [ ] 一、二、三課各按設定的成員與擷取時窗透過後端呼叫 eCIM `ReviewWork`；服務端憑證不傳送至瀏覽器。
- [ ] 課長只能觸發本課同步；每位成員的成功、失敗與上次成功時間可見，失敗不被當成空工作清單。
- [ ] 相同 Work ID 與來源期間重匯不產生重複候選；來源明細可追溯至 eCIM 工作。
- [ ] 以可控制的 eCIM 回應測試成功、部分失敗及重試，並由 Angular 畫面展示來源狀態。
