# 01 — 拆出甘特圖元件

**What to build:** 甘特圖從單一大檔中拆成獨立元件，輸入為時程項目清單與外部交付，輸出為「點選某列」事件。現有編輯頁與正式版頁都改用此元件，使用者看到的畫面與互動完全不變。同時移除甘特圖上的「進入修訂表單」入口與時程項目的修訂紀錄顯示（修訂紀錄已確認移除，歷史交給 git）。

這是預先重構，讓後續新頁面可直接重用甘特圖。

依據：[簡化週報實作計畫](../../../docs/simplified-weekly-report-implementation-plan.md) 切片 4；[甘特圖輸入契約](../../weekly-report-simplified/issues/03-gantt-input-contract.md)。
