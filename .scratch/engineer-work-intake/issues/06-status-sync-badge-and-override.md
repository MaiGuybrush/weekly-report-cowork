# 06 — 狀態對應、徽章與覆寫暫停

**What to build:** 重傳後關鍵任務狀態依工程師狀態自動對應：已完成→完成（進度 100）；處理中、簽核中、待發佈→進行中；待執行→開放。中止只提示「工程師標示中止」，不自動取消，由課長決定並寫理由。已完成時實際結束日留空並標示「缺實際結束日」。每次自動變更在項目上顯示徽章與原狀態、原進度，頁籤顯示未確認數量；課長可逐項確認，或一鍵還原為原狀態（還原後該次上傳不再自動覆寫）。待確認記錄存進課別 JSON，不出現在正式週報文件。課長手動覆寫進度後，自動同步暫停，只顯示「工程師最新進度 X%」差異提示，可按「改回跟隨工程師」恢復。非專案項目只顯示工程師狀態，不自動變更。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 瀏覽器煙霧測試主流程：上傳、標註並寫 comment、挑到專案建立關鍵任務、再上傳新檔、看到狀態徽章與 +xx%
- [ ] 重新載入後徽章仍在，直到課長確認；未確認數量正確
- [ ] 發布文件不含待確認記錄
