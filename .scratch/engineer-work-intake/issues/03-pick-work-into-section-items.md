# 03 — 非專案頁籤挑選建立項目

**What to build:** 課長在重大系統異常、系統維護與營運、人力與組織異動、新技術評估四個頁籤，從工程師工作挑選任一層級的工作新增項目；挑選介面顯示被選工作及其下一層子工作，子工作也可直接勾選（再往下一層）。項目綁定單一 `workId`（來源連結），標題預填工作內容，內容預填課長 comment，其餘欄位由課長補。一個 `workId` 全站只能綁一個項目；列表上已綁定的工作標示「已綁定」。摘要選填。非專案項目不新增狀態欄，只顯示工程師狀態。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 單元測試：`workId` 全站唯一（重複綁定被拒）；父子可各自綁定；預填規則
- [ ] 課長挑一個子層工作建立項目，儲存重新載入後項目與綁定仍在
- [ ] 已綁定的工作在樹上標示並無法再次綁定
- [ ] 進度只取被選工作自己的 `percentage`，不彙總子工作
