# 05 — 關鍵鏈標示

**What to build:** 甘特圖標出「關鍵鏈」：以預估完工日（含里程碑）沿前置項目推得、決定專案最晚交付日的那條項目鏈。落在鏈上的項目有明顯標示，課長調整預估完工日後即時重算。不顯示 float 天數。

**Blocked by:** 02 — 預估完工日與預估偏差；03 — 相依線

**Status:** done

- [x] 關鍵鏈以預估日期計算：有填預估完工日用之，否則沿用預設規則。
- [x] 鏈上的任務、階段、里程碑皆有明顯標示，圖例有說明。
- [x] 沒有任何相依的專案，以最晚結束的項目視為關鍵鏈，不報錯。
- [x] 已取消項目不參與計算。
- [x] 延後鏈上某任務的預估完工日，標示範圍隨之改變。
- [x] 測試涵蓋：單鏈、分叉合流、無相依、有取消項目。
