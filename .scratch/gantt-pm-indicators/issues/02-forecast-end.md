# 02 — 預估完工日與預估偏差

**What to build:** 課長可為進行中或逾期的關鍵任務填寫選填的「預估完工日」。甘特圖在實際條尾端以虛線延伸到預估完工日，偏差欄在項目完成前顯示淡色的「預估 +N 天」。未填時取計畫完成日與基準日中較晚者。階段不單獨填寫，取其未取消子任務中最晚的預估完工日；里程碑不適用。

**Blocked by:** 01 — 基準日改為可注入

**Status:** done

- [x] 任務編輯區有預估完工日欄位，階段與里程碑沒有。
- [x] 預估完工日早於實際開始日（無實際開始時為計畫開始日）時無法存檔，並顯示原因。
- [x] 項目標記完成或取消時，預估完工日自動清除。
- [x] 進行中任務填寫後，實際條尾出現虛線，偏差欄顯示「預估 +N 天」並與實際偏差樣式區分。
- [x] 未填且已逾期的任務，預估完工日取基準日。
- [x] 階段的預估完工日取子任務最晚者，子任務皆無預估時沿用同一套預設規則。
- [x] 後端不需變更；既有資料沒有該欄位時畫面正常。
- [x] 測試涵蓋：預設值、驗證、清除、階段彙總。
- [x] 更新解決方案設計文件，補上欄位與畫面規則。
