# 06 — 專案健康度納入預估延後

**What to build:** 專案健康度新增「預估延後」：未完成項目的預估完工日晚於計畫完成日，但尚未逾期時，健康度為需注意（`warn`），文字為「預估延後 N 項」，優先順序在「曾延後」之前、「逾期」之後。進度落後與關鍵鏈不影響健康度。

**Blocked by:** 02 — 預估完工日與預估偏差

**Status:** done

- [x] 有未逾期、未完成且預估完工日晚於計畫完成日的項目時，健康度顯示「預估延後 N 項」。
- [x] 已逾期的項目仍歸「逾期」，不重複計入預估延後。
- [x] 優先順序為：逾期、預估延後、曾延後、依計畫。
- [x] 已取消與已完成項目不計入。
- [x] 測試涵蓋：各狀態組合與優先順序。
