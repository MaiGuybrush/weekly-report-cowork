# 03 — 相依線

**What to build:** 甘特圖顯示前置項目的相依線。點選一列時，高亮並畫出其上下游的連線；另有「顯示全部」開關可一次顯示所有連線。端點位於已收合階段底下時，線接到所屬階段條。相依一律為「完成才開始」，不含延遲天數。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 甘特圖資料帶有每個項目的前置與後續。
- [x] 點選有前置或後續的列，連線與相關列被高亮；未點選時預設不畫線。
- [x] 「顯示全部」開關可畫出所有連線，再次點擊關閉。
- [x] 收合階段後，原本接到子任務的線改接到該階段條；展開後恢復。
- [x] 已取消項目不畫線。
- [x] 既有順序衝突與搶先開始警示維持不變。
- [x] 測試涵蓋：連線端點的決定（含收合時改接階段）。
