# 03 — 維護系統別：資料欄位與正式版分組

**What to build:** 維護項目新增選填的系統別，正式版維護章節依系統別分組。三課相同系統別合併於同一標題下；系統別依第一次出現的順序（課別一、二、三，課檔內原順序）排列，未填者歸入「未分類」並排最後；名稱比對只去除前後空白，其餘須完全相同（含大小寫）。既有沒有此欄位的項目視為未分類，不做遷移。系統異常、人力調整、新技術不分組。詳見 [規格](../../../docs/report-chapter-restructure-spec.md)，詞彙見 [CONTEXT.md](../../../CONTEXT.md) 的「系統別」。
