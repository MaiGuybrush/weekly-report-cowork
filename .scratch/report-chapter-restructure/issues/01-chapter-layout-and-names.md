# 01 — 章節重排與新名稱

**What to build:** 處會週報正式版改為依章節彙整三課內容，不再有課別分區。順序為管理摘要與待決策事項、專案、系統異常、維護、人力調整、新技術、附錄。專案依課別（一、二、三）再依各課原順序排列，不加課別標題；非專案項目不標示課別；某章節無任何項目時不顯示標題；系統異常依出現順序。編輯頁籤改用同一組新名稱（專案、系統異常、維護、人力調整、新技術）。此票維護章節仍是平面清單。詳見 [規格](../../../docs/report-chapter-restructure-spec.md)，詞彙見 [CONTEXT.md](../../../CONTEXT.md) 的「週報正式章節」。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 新增章節彙整純函式（輸入三個課檔，輸出依序的章節與項目）；單元測試涵蓋章節順序、專案課別排序、空章節省略、課檔缺項
- [ ] 正式版不再出現「第一課／第二課／第三課」標題；章節標題順序與名稱如規格
- [ ] 編輯頁籤與正式版使用同一組新名稱
- [ ] 舊版正式版以同一規則顯示
- [ ] 既有煙霧測試中以課別區塊定位正式版的斷言改為依章節定位，其餘發布驗證意圖不變
- [ ] `npm run check` 與 `npm run smoke` 通過
