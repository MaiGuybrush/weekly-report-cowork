# 04 — 維護頁籤：編輯端系統別

**What to build:** 課長在維護頁籤依系統別分組編輯。每組有標題與「新增維護項目」，頁籤上方有「新增系統別」，輸入名稱後同時建立一筆帶該系統別的空白項目，避免空組存檔後消失。系統別輸入欄提供本週三課已用名稱的建議；「未分類」組放最後。修改項目的系統別後項目移到對應的組，組內沒有項目時該組消失。組內「從工程師工作挑選」挑出的項目帶該組的系統別，頁籤頂端挑選則進「未分類」。系統異常、人力調整、新技術頁籤維持平面清單。詳見 [規格](../../../docs/report-chapter-restructure-spec.md)。
