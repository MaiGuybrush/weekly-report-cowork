# 08: 不可變的發布時程快照

**What to build:** 發布人能把當時完整且可解釋的專案時程納入正式週報；授權讀者打開固定發布連結時，所見日期、警示與修訂不會隨後續編輯改變。

**Blocked by:** 05 — 取消、重新啟用與關係清理；06 — 跨部門相依事項關聯。

**Status:** completed

- [x] 每次發布在一致讀取中保存三種項目的完整狀態、穩定身分、內外部連結、當時評估的警示、建立與修改歷史，以及解釋原始計畫偏差所需的值。
- [x] 發布讀者可檢視當時修訂與相依情況；後續工作版改期、更正、取消、移除連結或時間流逝，都不改變既有發布版的警示與內容。重新發布產生新的固定版本。
- [x] 發布沿用現有授權與不可變版本契約；後續加入 eCIM 證據時也必須把發布當時擷取的來源內容固定在快照中。
- [x] 以暫存資料庫及正式版讀取流程驗證前後版本隔離、警示凍結、歷史可讀及未授權讀者拒絕；更新受影響的報告結構與發布說明。
