# 05: 取消、重新啟用與關係清理

**What to build:** 週報維護人可在解決受影響的工作關係後取消時程項目，並可有紀錄地重新啟用；讀者仍能追溯被取消的承諾。

**Blocked by:** 04 — 專案內前置關係與警示。

**Status:** completed

- [x] 取消有後續項目的前置項目前，必須逐一移除或替換其連結；取消階段前，必須逐一重新歸屬、移到專案直屬或取消子任務，不能留下隱性歸屬。
- [x] 取消時移除剩餘的傳入連結，保留每次移除的原因與修訂；取消項目沒有有效內部相依關係，且取消不算完成前置工作。
- [x] 重新啟用須填原因並留下新修訂；階段或任務依保留的實際開始日回到進行中或開放，里程碑回到待達成。關係和子任務歸屬不自動恢復，新連結仍受現行驗證。
- [x] 已提交項目只能取消、不能硬刪除；取消項目預設不干擾有效時程，但授權讀者可取回其詳情與歷史。
- [x] HTTP 與編輯流程驗證取消前的解決要求、重新啟用狀態、未恢復連結及修訂持久性。
