# 03: 單日重要里程碑

**What to build:** 週報維護人可把交付或決策設為單日重要里程碑，改期並明確確認達成；讀者可分辨最初承諾、最新目標與實際達成日。

**Blocked by:** 01 — 專案階段與完整修訂紀錄。

**Status:** completed

- [x] 建立時必填單一目標日；資料契約與表單都不把里程碑當成起訖日期區間。原始目標、最新目標及實際達成日分別保存。
- [x] 待達成、已達成、已取消為明確狀態；目標日已過不自動達成。確認達成須填實際日期，重開時清除目前達成日但保留舊值於修訂。
- [x] 改期、更正達成日、重開與原始目標誤植更正均需原因及完整前後值；一般改期不重設相對原始目標的總偏差。
- [x] 清單及詳情在未達成時以最新目標日為主要日期，達成後以實際達成日為主要日期，仍能查看最新目標與歷史。
- [x] 授權 HTTP 與瀏覽器驗證必填日期、逾期未達成、達成和重開，以及畫面和發布資料均無里程碑日期區間。
