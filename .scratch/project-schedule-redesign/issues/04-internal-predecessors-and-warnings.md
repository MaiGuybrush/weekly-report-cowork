# 04: 專案內前置關係與警示

**What to build:** 週報維護人可為階段、關鍵任務及里程碑建立前置項目，讀者可看見改期與實際推進對後續項目的影響，同時仍允許例外工作繼續。

**Blocked by:** 02 — 關鍵任務與負責人；03 — 單日重要里程碑。

**Status:** ready-for-agent

- [ ] 同一專案內每項可有多個前置和後續項目；拒絕自我相依、循環、跨專案連結，以及階段與其直接子任務之間的連結。階段歸屬本身不產生前置關係。
- [ ] 建立或移除連結需原因並留下雙方可追溯的修訂。前置計畫變動即使仍可行，也通知受影響的後續項目。
- [ ] 當前置的目前計畫或實際完成日晚於後續的預計或實際開始日，顯示順序衝突；同日完成及開始視為可行。後續已開始而前置未完成時顯示即時警示。
- [ ] 前置完成後清除適用的即時警示；實際日期已顯示搶先開始時保留歷史順序衝突，直到有紀錄的日期更正解除。移除連結只清除目前視圖警示，不抹除歷史。
- [ ] 警示不阻止開始或完成，不自動變更後續日期；授權 HTTP 與畫面驗證不同項目種類、警示時序及可繼續工作。
