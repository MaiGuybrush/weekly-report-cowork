# 06: 跨部門相依事項關聯

**What to build:** 週報維護人可把其他部門承諾的交付事項連到受影響的專案時程項目，讓讀者辨認外部風險及責任單位。

**Blocked by:** 02 — 關鍵任務與負責人；03 — 單日重要里程碑。

**Status:** ready-for-agent

- [ ] 跨部門相依事項沿用現有管理紀錄，保留供應人或單位、到期日及狀態；可連到同一專案中一個或多個階段、任務或里程碑，拒絕跨專案關聯。
- [ ] 連結及移除需原因，並可在受影響項目與管理紀錄上追溯；未完成或逾期交付在項目詳情顯示獨立的外部交付提醒。
- [ ] 外部紀錄不參與專案內循環、前置順序或完成判定，也不會自動更改項目日期或狀態。
- [ ] 授權 HTTP 與畫面驗證跨專案拒絕、提醒與內部警示分離及歷史留存。
