# 07: 參與者進度與時程提案

**What to build:** 有權參與的課長或任務負責人可回報工作進度與建議日期，週報維護人可據此決定是否修改專案承諾；沒有帳號的負責人可由維護人代為記錄來源。

**Blocked by:** 02 — 關鍵任務與負責人。

**Status:** ready-for-agent

- [ ] 有權帳號經現有協作路徑提交進度和提案，能辨識對應關鍵任務；無帳號負責人的資訊由維護人記錄，並標明原始來源。
- [ ] 提案不直接變更關鍵任務的目前計畫、實際日期或完成狀態；維護人採納後仍走租約、版本、原因和修訂流程。
- [ ] 任務負責身分本身不給予時程編輯權；參與課長、無關使用者及讀者的讀寫權限由後端檢查，歷史讀取沿用專案讀取權限。
- [ ] 授權 HTTP 與畫面驗證提案可見性、維護人採納與越權拒絕。
