# 09: 完整時程跨週延續

**What to build:** 週報維護人建立下週草稿時，持續編輯同一專案的承諾及歷史，不必重建階段、任務、里程碑或相依關係。

**Blocked by:** 08 — 不可變的發布時程快照。

**Status:** ready-for-agent

- [ ] 新週從前週最新已發布版建立獨立工作版本，延續完整時程圖、穩定邏輯身分、建立與修改歷史，以及已完成和已取消項目；預設畫面仍可隱藏取消項目。
- [ ] 內部前置連結、外部事項關聯及後續加入的來源連結均與相應時程項目一起延續，不指向前週工作版的可變資料。
- [ ] 新週建立後，修改或重新發布前週不會靜默改變已建立的新週；新週的修改也不會改變前週任何正式版本。
- [ ] 透過現有報告 API 與暫存資料庫驗證延續、身分與歷史、相依關係，以及兩週工作版和正式版的隔離。
