# 11: 手動連結 eCIM 工作證據

**What to build:** 週報維護人可挑選一筆或多筆 eCIM 工作支持關鍵任務的進度說明；讀者能在工作版和正式發布版查看對應週次所用的來源證據。

**Blocked by:** 09 — 完整時程跨週延續。

**Status:** ready-for-agent

- [ ] 維護人明確選取、增減關鍵任務來源連結；一項任務可有多筆來源，同一 eCIM 工作跨週保有穩定身分，每次引用或同步所用內容可追溯。
- [ ] eCIM 匯入或重整不得自行建立、改期、完成、取消關鍵任務，也不得覆寫人工承諾；來源變動後仍能辨識先前引用的內容。
- [ ] 發布版固定保存發布當時的來源證據及連結；之後同步與跨週延續不改變既有發布證據，新週可延續連結並取得自己的來源狀態。
- [ ] 授權 HTTP 與瀏覽器驗證手動挑選、多來源、跨週穩定身分、同步不改承諾，以及發布前後的證據隔離。
