# 01 — 進度規則與顯示

**What to build:** 階段與關鍵任務有「進度」（0–100）。進行中的項目可在現有時程明細填寫，階段有子任務時由子任務推算，專案標頭並列「專案整體進度」與「完成 x/y」，甘特圖實際條旁標示 `NN%`，發布文件唯讀顯示。規則與詞彙以 [規格](../../../docs/project-progress-grid-spec.md) 與 `CONTEXT.md` 為準。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 純函式單元測試先寫（tdd）：有效進度與顯示規則、狀態聯動（完成 100、開放 0）、階段推算（排除取消、無子任務時手動、完成時 100、等權平均四捨五入）、專案整體進度（階段與直接隸屬任務各一單位、里程碑與取消不計、無單位顯示「—」）、缺值視為 0、0–100 夾限，再實作至通過
- [x] 只有進行中的階段／任務可輸入進度；狀態改為進行中時進度留空；進行中未填顯示「—」
- [x] `progress` 寫入 JSON 白名單，推算值不寫入；沒有 `progress` 的舊資料與舊發布快照正常顯示
- [x] 專案標頭顯示專案整體進度並保留「完成 x/y」，編輯頁與發布文件一致
- [x] 甘特圖實際條旁標示進度，發布文件唯讀顯示且維持收合預設
- [x] 煙霧測試斷言進度輸入、缺值「—」與標頭文字
