# 02 — 時程 grid 取代卡片明細

**What to build:** 編輯畫面改為甘特圖在上、時程 grid 在下。grid 是一列一個項目的表格，有固定最大高度與自己的捲軸，表頭固定，可與甘特圖對照著看。階段有收合箭頭，與甘特圖共用展開狀態，編輯畫面預設展開。版面參考 `proto-types/weekly-report-ui.html`。

**Blocked by:** 01 進度規則與顯示

**Status:** done

- [x] 編輯畫面每個專案的順序為標頭、甘特圖、grid、外部交付；多專案各有自己的甘特圖與 grid
- [x] 欄位：類型、名稱（任務含「所屬階段」下拉）、負責、狀態、進度、計畫起訖、實際起訖、前置項目、操作；起訖沿用日期範圍選擇器，里程碑為單日
- [x] grid 最大高度約 50% 視窗高度，垂直與水平捲軸，表頭固定；窄螢幕橫向捲動，不改卡片
- [x] 列順序與甘特圖一致（階段、其任務、直接隸屬任務、里程碑），依顯示排序、不改資料陣列順序；已取消項目灰階留在原組內，不受甘特圖「顯示已取消」影響
- [x] 既有功能不退化：佐證面板（展開在該列下方）、取消、重新啟用、刪除、前置項目與錯誤提示、外部交付表
- [x] 階段列有收合箭頭，與甘特圖共用展開狀態；編輯預設展開，發布文件維持收合預設
- [x] 煙霧測試涵蓋甘特圖在 grid 上方、捲軸、表頭固定、既有操作
