# 05 — 工時總覽與工時警示

**What to build:** 工具列下方出現「工時總覽」表，課長一眼看出每位工程師的工時與主要耗時工作，並對工時偏離標準者警示。詳見 [規格](../../../docs/engineer-page-redesign-spec.md)，詞彙見 [CONTEXT.md](../../../CONTEXT.md) 的「工時警示」。

- 欄位：姓名（點了跳轉，沿用 03 的跳轉）、工作時數、休假時數、主要耗時工作；休假為 0 時淡色。
- 主要耗時工作：該工程師頂層工作中本週工時最大的前兩項，格式「內容（12H）」，同時數依彙整檔順序；點了跳到頁內該工作列，不外連。
- 工時警示：工作時數＋休假時數 ≤38（不足）或 ≥44（過量）時標示，並可辨識方向；39 與 40 至 43 不警示。
- 最後一列為課別合計（工作、休假加總），不套用警示。
- 總覽可收合，預設展開，狀態不持久化。
- 名冊簡化為「名字、工時、★ 數」，不再畫工時條，細節交給總覽。
