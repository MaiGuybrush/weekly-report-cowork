# 03 — 名冊與跳轉

**What to build:** 課長在工程師進度頁左側看到固定名冊，點工程師姓名就捲到該工程師的工作，網址 hash 同步，重新整理後回到原位。同時建立「工程師頁模型」純函式模組的計數函式。詳見 [規格](../../../docs/engineer-page-redesign-spec.md)。

- 名冊每人顯示姓名、工作時數、★ 數、有評語的工作數；★ 與評語數包含所有層級的子工作；順序維持彙整檔順序。
- 隨捲動標示目前所在的工程師。
- 點名冊捲到對應區塊，以 `replaceState` 寫入 hash（工程師 `e-<帳號>`、工作 `w<編號>`），不增加瀏覽器歷史；載入時依 hash 捲到目標並短暫閃示。
- 尊重減少動態設定（不平滑捲動、不閃示）。
- 窄螢幕：名冊變成頂部橫向捲動的名字列，其餘單欄。
- 工程師頁模型：遞迴計算某工程師所有層級的 ★ 數與有評語工作數。
