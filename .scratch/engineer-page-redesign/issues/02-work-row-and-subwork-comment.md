# 02 — 工作列：編號連結與子工作獨立評語

**What to build:** 課長在工程師進度頁看到逐層縮排的工作列，工作編號是連到工作系統的連結；comment 預設收起，點 💬 才展開輸入；子工作（任一層）與父工作一樣可各自獨立標 ★ 與寫 comment。詳見 [規格](../../../docs/engineer-page-redesign-spec.md)。

- 工作遞迴展開（最深三層），依深度縮排；有子工作的列左側有 chevron，可個別收合，預設展開。
- 每個工作編號是連結，網址樣板由前端設定提供，新分頁開啟並設 `noopener`。
- 評語互動：收起 → 點 💬 或引用條展開並自動聚焦 → 失焦即存；Esc 捨棄本次編輯；有內容顯示可再點擊的引用條，清空則移除；有評語的 💬 樣式不同。
- 儲存失敗：重新載入以丟棄未存輸入，頁首顯示錯誤。
- 有上週評語時，評語區上方顯示一行灰字；子工作看自己編號的上週評語。
- 「本週彙整未出現」的工作淡化並保留原提示；耗時與 RMS 標記沿用。
- 唯讀身分（部級主管、別課課長）不顯示 💬 與輸入框，只顯示不可點擊的引用條。
