# 08 — 正式版文件、發布流程與版本下拉

**What to build:** 正式版改為單欄文件：管理摘要、待決策事項、三課；標題列含「週次 · vN」、版本下拉、列印鈕；空課略過標題；專案標頭帶健康度；甘特下方外部交付唯讀簡表、任務列尾 `📎 N`（title 帶摘要）、項目下方可點來源連結、人事項目顯示「交接／影響／下一步（生效日）」。發布：固定儲存列的「發布 {週}」先開 `<dialog>` 確認；部級跨課檔髒時停用；按下後顯示「發布中…」並停用；成功導向新版本，失敗顯示於儲存列。版本下拉依週 `<optgroup>`，週次與版本新到舊，標籤「v3 · 10/09 發布」；非最新版標題列旁顯示「舊版」膠囊。整併列印規則，健康度與甘特條紋可印。
