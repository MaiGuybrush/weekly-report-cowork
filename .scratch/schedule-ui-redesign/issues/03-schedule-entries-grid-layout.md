# 03 — 時程明細多欄緊湊網格排版重構 (Schedule Entries Multi-Column Grid Layout)

**What to build:**
重構專案時程明細區塊的佈局與表單呈現。將原本「一欄一行」垂直堆疊 8～10 行的鬆散佈局，升級為現代化、高空間利用率的 2 列響應式網格卡片（CSS Grid）。第一列整合基本屬性（類別、名稱、所屬階段、負責人、狀態），第二列整合時程與依賴（計畫起訖日曆、實際起訖日曆、前置項目多選下拉、佐證與操作按鈕）。卡片垂直高度大幅精簡，大幅減少滾動距離，並在小螢幕上具備自適應折行。

**Blocked by:**
- 01 — 輕量日期範圍選擇器元件 (Date Range Picker Component)
- 02 — 前置項目緊湊下拉多選元件 (Predecessors Multi-Select Component)

**Status:** done

- [x] 第二列整合時程與關聯：計畫起訖範圍日曆、實際起訖範圍日曆（或里程碑單日日曆）、緊湊前置項目多選元件、佐證按鈕、取消/刪除按鈕
