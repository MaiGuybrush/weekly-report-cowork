# 01 — 輕量日期範圍選擇器元件 (Date Range Picker Component)

**What to build:**
一個輕量、無外部相依的日期範圍選擇元件，支援區間選取（Range）與單日選取（Single）雙模式。使用者點擊輸入框可開啟彈出式月曆浮層，依序點選起始日與結束日，在滑鼠懸停時能預覽所選區間；具備反向點選自動校正（先點較晚日期再點較早日期時自動調正順序）與雙擊單日區間防呆。整合型輸入框顯示起訖日期摘要（如 `YYYY-MM-DD ～ YYYY-MM-DD`），並提供清除與回到今天按鈕，且能與底層日期模型雙向同步。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 支援 `range` 模式：第一次點選設定起日，第二次點選設定迄日，選取完成後自動同步
- [x] 滑鼠在日曆上懸停時，即時高亮顯示預計選取的日期區間
- [x] 防呆校正：若第二次選取的日期早於第一次，自動調整較早者為起日、較晚者為迄日
- [x] 支援同一天點選（起訖為同日）的單日區間
- [x] 支援 `single` 模式：單次點選即完成日期選擇並關閉日曆（供里程碑使用）
- [x] 輸入框顯示格式化區間文字，並提供快速清除按鈕
- [x] 具備「今天」捷徑按鈕與月份切換導航功能
- [x] 點選日曆外部區域時自動關閉浮層
