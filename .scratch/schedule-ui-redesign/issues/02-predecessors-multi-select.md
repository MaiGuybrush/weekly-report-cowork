# 02 — 前置項目緊湊下拉多選元件 (Predecessors Multi-Select Component)

**What to build:**
一個高度緊湊的前置項目多選下拉元件。將原本佔用多行垂直空間的原生多選選單，濃縮為單行高度控制項。未開啟時以摘要徽章或標籤顯示已勾選的前置項目；點擊展開浮層提供核取方塊（Checkboxes）供使用者直覺點選切換多個前置依賴。底層同步更新所選項目 ID 清單，並維持既有測試所需的選單屬性與資料同步。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 收合狀態下高度與一般文字輸入框一致（單行高度）
- [ ] 收合時以標籤徽章（Pills）或清晰文字摘要展示目前已選擇的前置項目名稱
- [ ] 點擊觸發框可展開核取清單浮層，每項前置項目具備獨立 Checkbox 供切換選取
- [ ] 支援全選/全部清除或逐項勾選
- [ ] 點擊浮層外部能自動關閉
- [ ] 底層狀態與選取的 ID 陣列保持雙向同步，且支援停用（disabled）狀態
